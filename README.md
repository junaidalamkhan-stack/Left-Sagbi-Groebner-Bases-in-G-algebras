# Left Sagbi–Gröbner Bases in G-Algebras

The Singular library `ncsg.lib`, by Muhammad Abdul Basit Khan and Junaid Alam Khan, is the companion code for the article

> M. A. B. Khan and J. A. Khan, **Left Sagbi–Gröbner bases in G-algebras**.
> Department of Mathematical Sciences, Institute of Business Administration (IBA), Karachi, Pakistan.

The article extends Miller's Sagbi–Gröbner bases to G-algebras. For a subalgebra S generated by a finite Sagbi basis H of a G-algebra A, and a left ideal I ⊆ S, it defines left SG-reduction (Algorithm 1) and left Sagbi–Gröbner bases (left SG-bases), proves a Buchberger-style criterion through an explicit syzygy family (Theorem 3.15), and gives a terminating algorithm for a finite left SG-basis (Algorithm 2). The library implements these for the computer algebra system [Singular](https://www.singular.uni-kl.de), using its noncommutative subsystem Plural.

## Installation

Requires Singular (tested with 4.3.2). Copy `ncsg.lib` to your working directory, or to a directory on Singular's library search path (`SINGULARPATH`), and load it with `LIB "ncsg.lib";` (it loads `nctools.lib` itself). The procedures declare local variables inside loops, so Singular prints `// ** redefining …` notes; `option(noredefine);` suppresses them.

## Quick start (Example 3.21 of the article)

```
option(noredefine);
LIB "ncsg.lib";
ring R = 0, (x, d), lp;
matrix C[2][2]; C[1,2] = 1;
matrix D[2][2]; D[1,2] = 1;                // d*x = x*d + 1
def A1 = nc_algebra(C, D);                 // first Weyl algebra
setring A1;
ideal H_sub = x^2, x*d, d^2;               // Sagbi basis of the subalgebra S
ideal G_ideal = x^4*d^2, x^3*d^3 + 3*x^2*d^2 + x*d;
lsgb(G_ideal, H_sub, 10);                  // x4d2, x3d3+3x2d2+xd, x2d2+3xd, x3d, xd
```

## Procedures

| Procedure | Purpose |
|---|---|
| `lsgb(F, H, max_iter)` | left SG-basis of the left ideal of S = K⟨H⟩ generated by `F` (Algorithm 2), for a Sagbi basis `H` of S; at most `max_iter` passes. New elements are normalized to leading coefficient 1 |
| `lsgred(f, H, G)` | final left SG-reductum of `f` via `G` over S (Algorithm 1) |
| `syzfam(g1, g2, H)` | syzygy family SyzFam(g₁, g₂) over S (Definition 3.12), from a commutative Gröbner basis of ⟨yᵢ − LM(hᵢ), z₁ − LM(g₁), z₂ − LM(g₂)⟩ |
| `lmult(M, H)` | an H-monomial whose leading monomial is the monomial `M` (Sagbi lift, Lemma 2.9), or 0 if there is none |
| `monsrch(target, gen_exps, idx, current_y)` | helper for `lmult`: searches for a representation of an exponent vector as a sum of the given exponent vectors |

The basering must be a G-algebra over ℚ (a Plural ring, e.g. defined with `nc_algebra`) with a global ordering, and `H` must be a Sagbi basis of S (Remark 3.18); Sagbi bases in G-algebras can be computed with `ncsagbi.lib` ([Sagbi-Bases-in-G-algebras](https://github.com/junaidalamkhan-stack/Sagbi-Bases-in-G-algebras)).

## Tests

```
./run_tests.sh             # run every session and compare with the stored outputs
./run_tests.sh --update    # regenerate the stored outputs
```

`tests/bounded_check.sing` is an independent bounded test of the left SG-bases of Examples 3.19 and 3.20, based on Definition 3.2: it forms all products m(H)·g with H-monomials m(H) up to a degree bound, computes the leading monomials of their linear span by Gaussian elimination, and checks that each is left SG-reducible by the basis. A failure proves that a set is not a left SG-basis, and passing is evidence, not a proof. As negative controls it detects that the input generators of both examples are not left SG-bases. All outputs were produced with Singular 4.3.2 (build 4330) on Ubuntu 24.04.
